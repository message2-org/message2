# Release security checklist

- [ ] SAST/Dependency scan clean or accepted with waivers.
- [ ] Secrets rotation completed for release environment.
- [ ] TLS certificate validity checked for both domains.
- [ ] Privileged-access transparency events verified end-to-end.
- [ ] E2EE integration tests pass for 1:1 and group chat.
- [ ] Audit log retention and immutability settings verified.
- [ ] Disaster recovery rehearsal executed in last 30 days.
